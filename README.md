# 🧠 Игры разума 🧠

Добро пожаловать в проект **"Игры разума"**! Это набор консольных игр, которые помогут вам прокачать логику, математические навыки и внимание. Каждая игра — это небольшое испытание для вашего мозга. 🚀

---

## 🛠 Установка и запуск

1. Склонируйте репозиторий:
```bash
git clone https://github.com/ваш-аккаунт/frontend-project-44.git
```
2. Перейдите в директорию проекта:
```bash
cd frontend-project-44
```
3. Установите зависимости:
```bash
make install
```
4. Запустите игру:

```bash
brain-even  # или brain-calc, brain-gcd, brain-progression, brain-prime
```
